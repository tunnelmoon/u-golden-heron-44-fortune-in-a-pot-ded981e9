# Fortune in a Pot

Entry for the make.fun bounty [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9).

One kind, funny fortune for the houseplant on the windowsill:

> A sunny morning is coming: you will lean toward it, grow two new leaves, and be forgiven for the one you dropped.

`main.ts` writes that line to `/output/entry.txt`, after checking it is one line of 1 to 120 characters and not only whitespace.
